This is the codebase for a project called EAS Tools. This codebase is a fully in-browser encoder, decoder, etc. for the United States Emergency Alert System (EAS) and the Canadian Alert Ready system. The project is structured to handle incoming EAS messages, process them, and make them available for further processing, analysis, or relaying to other systems. The project is designed to be a comprehensive toolkit for working with EAS messages, providing users with the ability to encode, decode, and analyze messages in real-time.

When working with the codebase, it is important to understand the following major components of the project:

**All Local**: Nearly everything is done locally in the browser, with no server-side processing. This means that all encoding, decoding, and analysis of EAS messages is performed on the user's device, ensuring privacy and security. The ONLY exception is Web TTS, which MUST use server side processing to generate speech synthesis.

**Accuracy**: The project is designed to be as accurate as possible in its handling of EAS messages, adhering to the specifications outlined in the relevant standards and guidelines. This includes proper handling of message formats, encoding schemes, and Part 11 of the FCC guidelines.

**User Interface**: The project includes a user-friendly interface that allows users to easily interact with the various components of the toolkit. This includes features for encoding and decoding messages, analyzing message content, and viewing message details in a clear and organized manner. The interface is designed to be intuitive and accessible, making it easy for users of all skill levels to work with EAS messages, especially the visually impaired, as the interface is designed to be fully accessible and compatible with screen readers and other assistive technologies. This is important, as the EAS system is a critical component of public safety, and it is essential that all users, including those with visual impairments, have access to the information and tools they need to effectively work with EAS messages.

**No Commits**: You DO NOT commit anything to the repository. This project is exclusively handled by me commit wise, and there is no need for you to run `git commit` or `git push` commands. All changes and updates to the codebase are managed by me, and contributors are not expected to make commits directly to the repository. This ensures that the codebase remains stable and consistent, and that all changes are thoroughly reviewed and tested before being integrated into the project.

**Extensive Testing**: The project includes extensive testing to ensure that all components are functioning correctly and that the toolkit is reliable and robust. This includes unit tests, integration tests, and end-to-end tests that cover all aspects of the project, from encoding and decoding messages to analyzing message content and displaying message details. The testing framework is designed to catch any issues or bugs early in the development process, allowing for quick resolution and ensuring that the project remains stable and reliable.
